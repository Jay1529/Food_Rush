# FoodRush -- Food Delivery Database Management System

## 📌 Project Overview

**FoodRush** is a SQL-based food delivery database management project
developed using **MySQL**.

The project models the major operations of a food delivery platform,
including:

-   Customer management
-   Restaurant management
-   Food categories and menu items
-   Order management
-   Delivery partner management
-   Payments
-   Reviews
-   Coupons and order discounts
-   Delivery tracking

The project also contains SQL queries for business analysis such as
revenue, sales, customer activity, delivery performance, ratings, and
order statistics.

------------------------------------------------------------------------

## 🛠️ Technologies Used

-   **SQL**
-   **MySQL**
-   **MySQL Workbench / MySQL-compatible environment**

## 🗂️ Database Structure

The `foodrush` database contains the following tables:

  Table                Purpose
  -------------------- ----------------------------------------
  `customers`          Stores customer information
  `restaurants`        Stores restaurant information
  `food_categories`    Stores food category information
  `delivery_partner`   Stores delivery partner details
  `coupons`            Stores coupon and discount information
  `menu_items`         Stores restaurant menu items
  `orders`             Stores customer orders
  `items`              Stores items included in orders
  `reviews`            Stores customer reviews and ratings
  `deliveries`         Stores delivery and timing information
  `payments`           Stores payment details
  `order_coupons`      Connects orders with applied coupons

------------------------------------------------------------------------

## 🔗 Database Relationships

The database uses **Primary Keys** and **Foreign Keys** to establish
relationships between related tables.

Examples:

-   Customers → Orders
-   Restaurants → Orders
-   Restaurants → Menu Items
-   Food Categories → Menu Items
-   Orders → Order Items
-   Orders → Payments
-   Orders → Reviews
-   Orders → Deliveries
-   Delivery Partners → Deliveries
-   Orders → Coupons through `order_coupons`
